Code for data analysis and visualization for The rate and spectrum of spontaneous mutations in anaerobically cultured lactic acid bacteria.

The `qmd_files` directory contains two Quarto notebooks. `make_tables.qmd` takes in data from various sources and produces csv files to be used for analysis and plotting. `analysis_plotting.qmd` takes in those tables and analyzes them and makes the plots and calculate statistics
The data used by `analysis_plotting.qmd` is in `data.tar.gz`.
